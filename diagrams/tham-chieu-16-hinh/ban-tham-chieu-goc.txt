Sơ đồ 14: Ngăn ngừa Ô nhiễm Connection Pool bằng SET LOCAL
```mermaid
sequenceDiagram
    autonumber
    participant App as Ứng dụng Backend
    participant Pool as Connection Pool (HikariCP)
    participant Conn as Kết nối Vật lý PostgreSQL


    Note over App,Conn: GIAI ĐOẠN 1: REQUEST CỦA TENANT A
    App->>Pool: Thuê Connection
    Pool-->>App: Cấp phát Conn #1
    App->>Conn: BEGIN;
    App->>Conn: SET LOCAL app.current_tenant_id = 'Tenant_A';
    App->>Conn: SELECT * FROM boards; (RLS lọc theo Tenant_A)
    App->>Conn: COMMIT; (Ngữ cảnh Tenant_A TỰ ĐỘNG BỊ HỦY tại đây)
    App->>Pool: Trả Conn #1 về Pool


    Note over App,Conn: GIAI ĐOẠN 2: REQUEST CỦA TENANT B (TÁI SỬ DỤNG CONN #1)
    App->>Pool: Thuê Connection
    Pool-->>App: Cấp phát lại Conn #1
    Note over Conn: Nhờ 'SET LOCAL', Conn #1 hoàn toàn sạch sẽ!<br/>current_setting('app.current_tenant_id') = NULL (Fail-Closed)
    App->>Conn: BEGIN;
    App->>Conn: SET LOCAL app.current_tenant_id = 'Tenant_B';
    App->>Conn: SELECT * FROM boards; (RLS lọc an toàn theo Tenant_B)
    App->>Conn: COMMIT;
```
