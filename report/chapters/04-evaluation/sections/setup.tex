\section{Baseline và hồ sơ kiểm chứng}\label{sec:baseline}
\subsection{Phiên bản mô tả và môi trường viết}
Phiên bản nguyên mẫu được mô tả có control migration V1--V6 và application migration V1--V12. Đây là trạng thái cấu trúc mã đã đối chiếu, không phải truy vấn trạng thái một hệ thống đang vận hành. Các checkpoint lịch sử và lượt kiểm tra mới được giữ riêng \Evidence{E01}, \Evidence{E04}.

Môi trường xuất bản có Python 3.12.3, XeTeX\slash TeX Live 2023, Biber và Poppler. Doctor xác nhận các package và đủ bốn kiểu Times New Roman. Maven hiện có là 3.9.11. Node.js Linux chưa dùng được; npm từ Windows báo không xác định được Node directory. Docker-dependent suite không có runtime Docker để thực thi trong lượt kiểm tra. Chi tiết backend thực tế và compiler được ghi trong biên bản mới \Evidence{E04}.

\subsection{Artifact cũ và kiểm tra mới}
Artifact Surefire có sẵn ghi 106 test, 0 failure\slash error, 47 skip vì Docker không khả dụng: 59 test được thực thi \Evidence{E03}. Commit thực thi chưa được xác lập. Lượt mới biên dịch lại 121 source và 27 test source, rồi mục tiêu test đạt: 106 tổng, 59 thực thi, 47 skip, 0 failure\slash error \Evidence{E04}. Maven và test runtime là Java 21.0.12.1; compiler fork là javac 25.0.4.1 với release 21 vì compiler đi kèm runtime 21 trên máy báo không hỗ trợ release 21. Đây không phải build hoàn toàn bằng JDK 21.

Mục tiêu verify chưa hoàn tất do thiếu plugin trong cache offline. Frontend\slash E2E chưa chạy lại vì thiếu Node\slash runtime stack. Không nâng nhãn ``test goal đạt'' thành ``verify đạt'', không suy 47 case Docker bị skip là pass và không dùng compiler fallback làm bằng chứng đã đạt môi trường verification chuẩn.

Báo cáo và các biểu mẫu được kiểm tra khổ A4, phông nhúng và tính nhất quán tham chiếu. Biên bản xuất bản nằm trong hồ sơ hỗ trợ; kết quả dàn trang không thay bằng chứng nghiên cứu hoặc kiểm chứng ứng dụng.
