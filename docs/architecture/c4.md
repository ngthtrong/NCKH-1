# C4 — Context, Container và Component

Mermaid dùng ký pháp flowchart portable; chú thích `TB` là trust boundary.

## 1. System Context

```mermaid
flowchart LR
    user["Sinh viên / Giảng viên\nTenant user"]
    sysadmin["Quản trị hệ thống"]
    research["Nhóm nghiên cứu"]
    system["SaaS quản lý công việc\nBridge Pool + Silo DB"]
    payment["Payment Sandbox\nVNPay / Stripe / Fake"]
    email["SMTP / Mailpit"]
    push["Web Push Service"]

    user -->|HTTPS: Kanban, member, resource| system
    sysadmin -->|HTTPS: tenant/payment/provisioning ops| system
    system -->|signed request / webhook| payment
    system -->|SMTP| email
    system -->|Web Push protocol| push
    research -->|k6/test/metrics; dữ liệu phi nhạy cảm| system
```

## 2. Container

```mermaid
flowchart TB
    browser["Browser SPA\nReact + TypeScript"]
    proxy["Caddy / Reverse Proxy\nHost routing + TLS"]
    api["API Process\nSpring modular monolith\nNo CREATE DATABASE privilege"]
    worker["Worker Process\nOutbox + notification + provisioning"]
    control[("Control PostgreSQL\nidentity, tenant, payment, jobs")]
    pooled[("Pooled PostgreSQL\nshared schema + tenant_id")]
    silo1[("Silo DB tenant A\napplication schema + tenant_id")]
    silon[("Silo DB tenant N\napplication schema + tenant_id")]
    object[("Shared Resource Storage\ntenant namespace + signed URL")]
    ext["Payment / SMTP / Web Push"]
    obs["Prometheus + Grafana\nJSON logs"]

    browser -->|HTTPS, tenant host| proxy
    proxy -->|trusted Host/request ID| api
    api -->|identity/routes/membership| control
    api -->|POOL resolved| pooled
    api -->|SILO resolved| silo1
    api -->|SILO resolved| silon
    api -->|authorized signed URL| object
    worker -->|jobs/outbox/control state| control
    worker -->|business outbox| pooled
    worker -->|business outbox| silo1
    worker -->|business outbox| silon
    worker -->|provision DB/role/migrate| pooled
    worker -->|provision DB/role/migrate| silo1
    worker -->|provider adapters| ext
    api -. metrics/logs .-> obs
    worker -. metrics/logs .-> obs
```

## 3. API component

```mermaid
flowchart LR
    req["HTTP request"] --> host["TenantRouteResolver"]
    host --> auth["TokenVerifier + SessionGuard"]
    auth --> membership["TenantMembershipGuard"]
    membership --> context["TenantContextFactory"]
    context --> limit["TenantTierRateLimiter"]
    limit --> controller["REST Controllers / OpenAPI"]
    controller --> service["Application Services"]
    service --> resolver["TenantDataSourceResolver"]
    resolver --> tx["Tenant Transaction Boundary"]
    tx --> policy["AuthorizationPolicy\nreads current ProjectMembership"]
    policy --> repo["Application Repositories"]
    service --> outbox["Outbox Writer"]
    service --> audit["Audit Writer"]
    context -. sanitized fields .-> telemetry["Log / Metric Enrichment"]
```

## 4. Worker/provisioning component

```mermaid
flowchart LR
    poller["Job/Outbox Poller"] --> lease["Lease + Idempotency Guard"]
    lease --> dispatcher{"Job type"}
    dispatcher --> provision["Provisioning State Machine"]
    dispatcher --> notify["Notification Dispatcher"]
    provision --> poolExec["PoolPlacementExecutor"]
    provision --> siloExec["SiloDatabaseExecutor"]
    poolExec --> migrate["Flyway Migration Runner"]
    siloExec --> privileged["Privileged DB Admin Adapter"]
    privileged --> migrate
    provision --> route["Tenant Route Registry"]
    notify --> inapp["InApp Writer"]
    notify --> smtp["SMTP Adapter"]
    notify --> vapid["WebPush Adapter"]
    provision --> audit["Audit + Diagnostic"]
    notify --> audit
```

## 5. Quy tắc biên

- Browser, provider callback và forwarded headers đều là dữ liệu không tin cậy.
- Chỉ proxy được cấu hình mới cung cấp trusted forwarding headers; API tự xác minh host allowlist.
- API và worker dùng database principals khác nhau; chỉ provisioning adapter có quyền quản trị DB.
- Control DB không join trực tiếp application DB; storage không tự quyết authorization.
- Observability là đường egress dữ liệu: phải redact và giới hạn cardinality/quyền xem.
